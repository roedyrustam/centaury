## 🚀 Quickstart

Scaffold a new Centaury application instantly:

```bash
bunx centaury create my-app --install
```

Or choose specialized archetypes:
```bash
# Minimal: Ultra-lightweight micro-signals + Bun Trie server (<1.5KB)
bunx centaury create my-minimal-app --template minimal --install

# Agentic: MCP v1.x + Ephemeral Generative UI + Astra Multimodal Gateway
bunx centaury create my-agent-app --template agentic --install
```
